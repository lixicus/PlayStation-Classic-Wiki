
# Wolf4SDLSD (Wolfenstein 3D Spear of Destiny)

![Logo](https://gitlab.com/modmyclassic/ports/wolf4sdl/-/raw/master/classic/psc_eris_sd/media/project_eris/etc/project_eris/SUP/launchers/wolf4sdl_sd/wolf3dsd.png)

**Note: It is required that you own the `Spear of Destiny Full and Mission Disks` version of Wolfenstein 3D**

## How to use

### Project ERIS (PlayStation Classic)

1. Download the .mod package from [the Project ERIS mods page](https://modmyclassic.com/project-eris-mods/)
2. Copy the .mod package to your USB to: `USB:/project_eris/mods/`
3. Plug in and boot up the PlayStation Classic. Project ERIS will automatically install.
4. Turn off the PlaySation Classic and plug in USB to PC (OR using SFTP...)
5. You need to copy and rename all your  `.SOD` files so they are ALL lowercase (including file extension)
6. Copy all your `.sod` files to: `USB:/project_eris/etc/project_eris/SUP/launchers/wolf4sdl_sd/`
