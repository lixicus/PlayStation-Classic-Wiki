
# Xash3D (Half Life 1 Engine)

![Logo](https://gitlab.com/modmyclassic/ports/xash3d/-/raw/master/classic/psc_eris/media/project_eris/etc/project_eris/SUP/launchers/xash3d/xash3d.png)

**Note: You are able to play a lot of different games that run with the Half Life 1 engine with Xash3D. We will just cover the basic use of adding Half Life 1**

## How to use

### Project ERIS (PlayStation Classic)

1. Download the .mod package from [the Project ERIS mods page](https://modmyclassic.com/project-eris-mods/)
2. Copy the .mod package to your USB to: `USB:/project_eris/mods/`
3. Plug in and boot up the PlayStation Classic. Project ERIS will automatically install.
4. Turn off the PlaySation Classic and plug in USB to PC
5. You need to copy and paste all the contents of your valve directory within your copy of Half Life 1  to: `USB:/project_eris/etc/project_eris/SUP/launchers/xash3d/xash/valve/` **BUT YOU MUST NOT OVERWRITE ANY FILES WHEN ASKED. JUST SKIP**

If for some reason you copied your local `valve` folder over to the `xash3d` directory and DID overwrite the files. You can install the mod again following steps 1-2 and it should resolve your issue.
