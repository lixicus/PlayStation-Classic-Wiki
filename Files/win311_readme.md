
# Windows 3.11

![Logo](https://gitlab.com/modmyclassic/ports/dosbox/-/raw/master/classic/psc_eris_311/media/project_eris/etc/project_eris/SUP/launchers/win311/win311.png)

**To set expectation, DOSBox emulation is very CPU intensive. Therefore if you are running DOSBOX on the following platforms you should expect the equivalent performance:**

- PlayStation Classic - Equivalent to a mid spec'ed 486.

## How to use

### Project ERIS (PlayStation Classic)

1. Download the .mod package from [the Project ERIS mods page](https://modmyclassic.com/project-eris-mods/)
2. Copy the .mod package to your USB to: `USB:/project_eris/mods/`
3. Plug in and boot up the PlayStation Classic. Project ERIS will automatically install.
4. Turn off the PlaySation Classic and plug in USB to PC (OR using SFTP...)
5. Extract all the 6 Windows 3.11 install floppy disks to `USB:/project_eris/etc/project_eris/SUP/launchers/win311/application/INSTALL/` (You can use 7zip to do this)
6. (Optional) You can add extra DOS program/games to `USB:/project_eris/etc/project_eris/SUP/launchers/win311/application/`
7. (Optional) DOSBox is mainly intended to be used with a Keyboard (and mouse if needed). However it does come with controller support through a file called `mapper.txt` you can create/edit your own `mapper.txt` to use within your DOSBox application
