![Logo](https://gitlab.com/modmyclassic/ports/ioquake3/-/raw/master/classic/psc_eris/media/project_eris/etc/project_eris/SUP/launchers/ioquake3/ioquake3.png)
## How to use

### Project ERIS (PlayStation Classic)

1. Download the .mod package from [the Project ERIS mods page](https://modmyclassic.com/project-eris-mods/)
2. Copy the .mod package to your USB to: `USB:/project_eris/mods/`
3. Plug in and boot up the PlayStation Classic. Project ERIS will automatically install.
4. Turn off the PlaySation Classic and plug in USB to PC (OR using SFTP...)
6. Copy all your quake 3 arena `.pk3` files to: `USB:/project_eris/etc/project_eris/SUP/launchers/ioquake3/.q3a/baseq3/`

**Note: ioQuake3 requires the full copy of Quake 3 Arena! The shareware version will not work**
