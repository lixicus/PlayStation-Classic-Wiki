
# CorsixTH (Enhanced Theme Hospital)

![Logo](https://gitlab.com/modmyclassic/ports/corsixth/-/raw/master/classic/psc_eris/media/project_eris/etc/project_eris/SUP/launchers/corsixth/corsixth.png)

**Warning! This is currently a keyboard and mouse only game! There is no gamepad support. At minimum you will need a USB mouse connected!**

**Note: This mod comes pre bundled with the shareware build of Theme Hospital. It is compatible with the following versions of Theme Hospital:**
- Theme Hospital CD 
- Theme Hospital (available for purchase from GOG)

**Bug alert: If you zoom in and out with the mouse wheel, you will likely crash the game due to lack of DRAM. This is a known bug with corsix-TH and when it is resolved we will patch this build**

## How to use

### Project ERIS (PlayStation Classic)
1. Download the .mod package from [the Project ERIS mods page](https://modmyclassic.com/project-eris-mods/)
2. Copy the .mod package to your USB to: `USB:/project_eris/mods/`
3. Plug in and boot up the PlayStation Classic. Project ERIS will automatically install.
 **(You can play the shareware version as is or continue to add the full game)**
4. Turn off the PlaySation Classic and plug in USB to PC (OR using SFTP...) 
5. Delete all the shareware game files in: `USB:/project_eris/etc/project_eris/SUP/launchers/corsixth/corsix-th_data/HOSP/` and copy & paste all your Theme Hospital game files in the same location.
