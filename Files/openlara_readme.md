# OpenLara (Enhanced Tomb Raider Engine)

![Logo](https://gitlab.com/modmyclassic/ports/openlara/-/raw/master/classic/psc_eris/media/project_eris/etc/project_eris/SUP/launchers/openlara/openlara.png)

## How to use

### Project ERIS (PlayStation Classic)

1. Download the .mod package from [the Project ERIS mods page](https://modmyclassic.com/project-eris-mods/)

2. Copy the .mod package to your USB to: `USB:/project_eris/mods/` 

3. Plug in and boot up the PlayStation Classic. Project ERIS will automatically install. 

4. Turn off the PlaySation Classic and plug in USB to PC (OR using SFTP...) 

5. Copy yourTomb Raider 1 Game Data and Audio data to: `USB:/project_eris/etc/project_eris/SUP/launchers/openlara` 

  **For example, if you use the PSX version:**
  - `USB:/project_eris/etc/project_eris/SUP/launchers/openlara/DELDATA/`
  - `USB:/project_eris/etc/project_eris/SUP/launchers/openlara/FMV/`
  - `USB:/project_eris/etc/project_eris/SUP/launchers/openlara/PSXDATA/`

  [Tomb Raider 1 Data Screenshot](https://cdn.discordapp.com/attachments/398987597592133632/575978927231860758/unknown.png)

6. Copy the Audio files to `USB:/project_eris/etc/project_eris/SUP/launchers/openlara`

  **For example, if you use the PSX version:**
  - (`USB:/project_eris/etc/project_eris/SUP/launchers/OpenLara/audio/`)

  [Tomb Raider 1 audio Screenshot](https://cdn.discordapp.com/attachments/398987597592133632/575980734679089162/unknown.png) 

7. Once you have extracted your game data to the port you should end up with something like:
  - `USB:/project_eris/etc/project_eris/SUP/launchers/OpenLara/DELDATA/*.RAW`
  - `USB:/project_eris/etc/project_eris/SUP/launchers/OpenLara/PSXDATA/*.PSX`
  - `USB:/project_eris/etc/project_eris/SUP/launchers/OpenLara/FMV/*.FMV`
  - `USB:/project_eris/etc/project_eris/SUP/launchers/OpenLara/audio/*.ogg`
